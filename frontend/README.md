# Nexcore — Frontend

This is the Next.js and React frontend application for the Nexcore Consultant Utilization & Billing Dashboard.

## Features
- **Executive Overview**: KPI metric tiles, utilization rates, and billable hour summaries.
- **Consultant Management**: Directory, capacity, rates, and profile details.
- **Time Tracking**: Timesheet logging, billable status, and approval workflows.
- **Rate Intelligence & Retainers**: Retainer consumption cards and billing analytics.
- **Modern UI**: Built with Radix UI, Tailwind CSS, Recharts, and Lucide icons.

## Getting Started

1. Install dependencies:
   ```bash
   pnpm install # or npm install
   ```

2. Run the development server:
   ```bash
   pnpm dev # or npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Scripts
- `npm run dev`: Starts the Next.js development server on port 3000.
- `npm run build`: Builds the production bundle.
- `npm run start`: Starts the production Next.js server.
- `npm run check`: Performs TypeScript type-checking without emitting.
